3. OpenCode

Qué es: un agente de programación de código abierto que funciona en la terminal (TUI3). Lee y edita tu proyecto, ejecuta comandos y permite cambiar de modelo en cualquier momento con /models.

Modelos que te ofrece:

4. Google AI Plus

Qué es: el plan de Google gratis durante 12 meses para universitarios en España. Se usa en la app de Gemini (web y móvil) e incluye 400 GB de almacenamiento. No se conecta a OpenCode.

Modelos que te ofrece: Gemini con límites de uso 2 veces más altos que la cuenta gratuita, Gemini Omni (generación de vídeo) y uso ilimitado de los cuadernos de estudio y de Gemini Live.

5. Tutorial: instalarlo todo paso a paso

Los comandos están pensados para Windows (PowerShell); en macOS y Linux son equivalentes.

Paso 1. Activar Copilot Student

  1. Entra en github.com/settings/education/benefits y pulsa Start an application. Usa tu correo @alumnos.uc3m.es y, si te lo pide, sube un justificante de matrícula.
  2. Cuando te aprueben, en el mismo panel busca Copilot y activa Copilot Student.
  3. Si solo te aparece Copilot Free o una pantalla de pago, no pagues nada: prueba en github.com/github-copilot/free_signup o espera unos días.

Paso 2. Instalar OpenCode

# Opción A: con Node.js
npm install -g opencode-ai
# Opción B: con Scoop o Chocolatey
scoop install opencode
choco install opencode
# macOS / Linux / WSL
curl -fsSL https://opencode.ai/install | bash

# Arrancar dentro de un proyecto y generar su AGENTS.md
cd C:\ruta\a\mi-proyecto
opencode
/init

Paso 3. Conectar Copilot Student

  1. Dentro de OpenCode, ejecuta /connect y elige GitHub Copilot → GitHub.com.
  2. Abre github.com/login/device, introduce el código que muestra la terminal y autoriza.
  3. Añade el plugin que activa el modo Auto en ~/.config/opencode/opencode.jsonc:
{
  "$schema": "https://opencode.ai/config.json",
  "plugins": ["@opeoginni/opencode-copilot-auto"]
}
  1. Reinicia OpenCode, ejecuta /models y elige GitHub Copilot → Auto (github-copilot/auto).

Paso 4. Activar los modelos gratuitos de OpenCode Zen

  1. /connect → OpenCode Zen → inicia sesión en opencode.ai/auth y copia tu API key.
  2. /models → elige uno con la etiqueta Free, por ejemplo opencode/big-pickle o opencode/nemotron-3-ultra-free.

Paso 5. Pedir Google AI Plus para estudiantes

  1. Con tu cuenta de Google personal (no la de la UC3M), entra en one.google.com/ai-student.
  2. Verifica la matrícula con SheerID5 usando el correo @alumnos.uc3m.es.
  3. Canjéalo antes del 31 de diciembre de 2026. Pide tarjeta: comprueba que sale a 0 € y apunta en el calendario cancelarlo antes de que pasen los 12 meses.

7. Avisos

  • Renovaciones automáticas: la oferta de Google pide tarjeta. Cancela antes de que acabe el periodo gratuito.
  • Privacidad: lo que envías a los modelos Free de Zen puede usarse para mejorarlos. No metas datos personales ni código confidencial.
  • Plugins de la comunidad: opencode-copilot-auto no es oficial y puede dejar de funcionar si GitHub cambia su API.
  • Las ofertas cambian: antes de recomendar algo, comprueba la página oficial.

8. Extra: Google Antigravity

Qué es: la plataforma de agentes de Google. Tiene app de escritorio, IDE y CLI (agy), y se puede usar gratis con cualquier cuenta de Google. Está muy bien aunque tenga modelos más antiguos que los de Copilot: da acceso gratuito a Claude Opus y Gemini Pro, que en otros sitios son de pago. La cuota es semanal, así que conviene reservarlo para las tareas importantes.

9. Trucos de OpenCode en la terminal

Comandos dentro de OpenCode

ComandoPara qué sirve
/modelsCambiar de modelo en mitad de la conversación, por ejemplo de Copilot Auto a Big Pickle cuando se acaban los créditos
/connectAñadir un proveedor nuevo o iniciar sesión otra vez
/newEmpezar una conversación nueva y limpia (alias /clear)
/sessionsVer las conversaciones anteriores y volver a cualquiera (alias /resume)
/undo · /redoDeshacer o rehacer el último mensaje, incluidos los cambios en los archivos (el proyecto tiene que ser un repositorio Git)
/compactResumir la conversación cuando se hace muy larga: gasta menos y el modelo no se pierde
/initCrear o actualizar el AGENTS.md con la descripción del proyecto
/exportGuardar la conversación en Markdown
/thinkingMostrar u ocultar el razonamiento del modelo
/themes · /help · /exitCambiar el tema de colores, ver la ayuda y salir

Atajos útiles

AtajoPara qué sirve
TabAlternar entre modo Plan (solo propone, no toca archivos) y modo Build (hace los cambios). Lo ideal es planificar primero y construir después
@archivoAñadir un archivo a la conversación, con búsqueda aproximada: ¿qué hace @src/main.py?
!comandoEjecutar un comando de terminal y pasarle la salida al modelo: !pytest
Arrastrar una imagenPasarle capturas o diseños al modelo
Ctrl+PPaleta con todos los comandos
Ctrl+X y luego MAbrir el selector de modelos sin escribir /models. Con Ctrl+X también funcionan N (nueva sesión), U (deshacer) y L (sesiones)
Ctrl+TCambiar la variante de razonamiento del modelo (más o menos "thinking")

Desde la terminal, sin abrir la interfaz

opencode -c                          # retomar la última conversación
opencode -m opencode/big-pickle      # arrancar directamente con un modelo
opencode run "explica este error"    # pregunta rápida sin abrir la interfaz
opencode models                      # listar los modelos disponibles
opencode upgrade                     # actualizar OpenCode

Para no tener que elegir modelo cada vez, se puede fijar uno por defecto en ~/.config/opencode/opencode.jsonc con la clave "model": "github-copilot/auto".

En la CLI de Antigravity (agy) hay comandos parecidos: /usage para ver la cuota, /plan para planificar antes de tocar código, /resume para retomar conversaciones y /diff para revisar los cambios.
